How to use

1. Click to identify a component

Activate the inspector, then click any element on the page. The extension detects the component name from React, Vue, CSS class names, or test IDs and copies it to your clipboard along with the page URL.

The copied text includes Component: (the detected name) and URL: — paste it directly into a comment or ticket.

2. Drag to capture a region

Instead of clicking, click and drag to draw a selection rectangle over any area. A cropped screenshot is saved to ~/Downloads/lgtm-inspector/ and the file path is included in the copied text so teammates (or Claude) can open it directly.

Installation

  1. 1
    Download the ZIP Click the button above, then download lgtm-inspector-standalone.zip from the latest release.
  2. 2
    Unzip it anywhere Extract to a stable location (e.g. your home folder). Do not delete the folder after installation.
  3. 3
    Open Chrome Extensions Navigate to chrome://extensions and turn on Developer mode (top right toggle).
  4. 4
    Load the extension Click Load unpacked and select the unzipped folder.
  5. 5
    Pin it to your toolbar Click the puzzle icon in Chrome's toolbar, then pin LGTM Inspector (Standalone) for easy access. The icon is green.
⌘ShiftI Toggle the inspector on any page. Customize at chrome://extensions/shortcuts.

Updating

  1. 1
    Download the new ZIP from the latest release Same link as above — always points to the latest version.
  2. 2
    Replace the old folder Unzip and overwrite the previous folder in the same location.
  3. 3
    Reload in Chrome Go to chrome://extensions, find LGTM Inspector (Standalone), and click the reload icon (↺).
